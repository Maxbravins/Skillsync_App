# SkillSync - Freelance Developer Marketplace

A full-stack MERN application connecting student developers with clients.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Authentication:** JWT with HTTP-only cookies

## Features
-  User authentication (Login/Register)
-  Role-based dashboards (Client/Developer)
-  Job posting and management (CRUD)
-  Job applications with cover letters
-  User profiles with avatar upload
-  Real-time dashboard updates
-  Notification system
